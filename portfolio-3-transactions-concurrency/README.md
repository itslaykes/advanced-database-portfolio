# Portfolio 3: Transactions and Concurrency

## Course
MIT 8103 – Advanced Database Systems

## Case Study
Laykes Online Store

## Introduction
This portfolio examines database transactions and concurrency control in the Laykes Online Store database.

## Objectives
- Understand database transactions.
- Demonstrate COMMIT and ROLLBACK operations.
- Explain ACID properties.
- Demonstrate transaction isolation.
- Understand concurrency problems and their control.
