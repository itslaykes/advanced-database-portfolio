# Portfolio 2: Query Processing and Optimisation

## Course
MIT 8103 – Advanced Database Systems

## Case Study
Laykes Online Store

## Introduction
This portfolio focuses on retrieving, processing and optimising data in the Laykes Online Store database.

## Objectives
- Write SQL queries to retrieve information.
- Use WHERE clauses to filter records.
- Use JOIN operations to combine tables.
- Perform aggregate calculations.
- Create database indexes.
- Examine query execution plans using EXPLAIN.
- Evaluate query performance.
