# Database Normalisation – Laykes Online Store

## First Normal Form (1NF)
The database satisfies First Normal Form because each column contains a single value, and each table has a primary key. For example, customer information is stored separately from product information.

## Second Normal Form (2NF)
The database satisfies Second Normal Form because it is in 1NF and every non-key attribute depends on the entire primary key. Each table uses a primary key to identify its records.

## Third Normal Form (3NF)
The database satisfies Third Normal Form because non-key attributes depend only on the primary key, not on other non-key attributes. Customer details, product details, payment information and delivery information are stored in separate tables.

## Conclusion
Normalisation improves the organisation of the Laykes Online Store database by reducing unnecessary data duplication and improving data integrity.
