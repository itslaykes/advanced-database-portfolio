# Portfolio 1: Database Design and Modelling

## Course
MIT 8103 – Advanced Database Systems

## Case Study
Laykes Online Store

## Project Description
This project focuses on designing a relational database
for an online store that sells football jerseys and other
sports products.

## Objectives
- Identify database entities.
- Design an Entity Relationship Diagram (ERD).
- Create relational database tables.
- Identify primary and foreign keys.
- Apply database normalisation.
