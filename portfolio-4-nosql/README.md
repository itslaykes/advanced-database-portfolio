# Portfolio 4: NoSQL and Advanced Data Models

## Project Title
Laykes Online Store – NoSQL Database Implementation

## Introduction
This portfolio demonstrates the implementation of a NoSQL database using MongoDB for Laykes Online Store.

## Database Used
MongoDB Community Server and MongoDB Compass.

## Database Name
laykes_online_store_nosql

## Collection
orders

## Objectives
- Understand NoSQL database concepts.
- Create a document-based data model.
- Insert and retrieve customer order documents.
- Demonstrate MongoDB queries.
- Compare relational databases with NoSQL databases.

## Implementation
MongoDB Compass was used to create the database and orders collection. Two sample customer orders were inserted.

## Conclusion
MongoDB provides a flexible document-based approach for storing customer and order information in an e-commerce business.
