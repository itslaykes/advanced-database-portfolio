# Portfolio 5: Distributed and Cloud Database Exercise

## Project Title
Laykes Online Store – Distributed and Cloud Database Design

## 1. Introduction
This portfolio explains how distributed and cloud database technologies can support Laykes Online Store as its customer base and business operations grow.

## 2. Business Scenario
Laykes Online Store sells football jerseys and sports products to customers in different locations. The business requires reliable access to customer, product, order and payment information.

## 3. Objectives
- Understand distributed database systems.
- Explain database replication and sharding.
- Examine database availability and consistency.
- Design a cloud database architecture.
- Understand how distributed databases support business operations.

## 4. Proposed Architecture
The proposed system uses a central cloud database with distributed access points to support customers and business operations across different locations.

## 5. Conclusion
Distributed and cloud database technologies can improve data availability, scalability and reliability for Laykes Online Store.
